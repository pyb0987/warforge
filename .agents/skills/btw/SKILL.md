# /btw — 사이드 질문

메인 작업 흐름을 흐트러뜨리지 않는 단발성 질문 처리.

## 동작

1. 기본값: 메인 에이전트가 짧게 직접 답한다.
2. 파일 수정, 장기 조사, trace 기록, Plans.md 변경은 하지 않는다.
3. 사용자가 명시적으로 서브에이전트/위임/독립 조사를 요청한 경우에만 Codex 서브에이전트를 사용한다.
4. 코드베이스 질문은 `explorer`, 일반 질문은 `default` 역할을 사용하고 모델 override는 지정하지 않는다.

## 실행

```
<instructions>
사용자의 질문: {{args}}

먼저 질문이 현재 메인 작업과 독립적인 단발성 질문인지 확인한다.

서브에이전트 사용 조건:
- 사용자가 "/btw를 별도 에이전트로 처리", "위임", "독립 조사", "parallel"처럼 명시적으로 요청한 경우만 사용
- 코드베이스 참조가 필요한 질문이면 agent_type: "explorer"
- 일반 지식 질문이면 agent_type: "default"
- model 필드는 지정하지 않음

그 외에는 메인 에이전트가 한국어로 간결하게 직접 답한다.

답변은 메인 작업과 분리된 참고 답변임을 과하게 설명하지 말고, 필요한 결론만 전달한다.
</instructions>
```
