# 리플레이 시스템 (런 외부 선택)

게임 시작 전 선택하는 3가지 시스템. N × M × 난이도 조합으로 리플레이성 확보.

## 1. 플레이특성 (커맨더)

런 시작 시 1명 선택. 게임 규칙 자체를 변경하여 최적 전략이 달라짐.

| 커맨더 | 특성 | 유도하는 전략 |
|--------|------|-------------|
| 🎲 도박꾼 | 리롤 50% 무료. ★3 합성 시 골드 절반 환급 | ★3 올인, 공격적 리롤 |
| 🌱 양성가 | 유닛추가 유닛 HP +5. 유닛 15+ 카드 발동상한 +1 | 물량 극대화 |
| ⚒️ 단조사 | 업그레이드 슬롯 +1 (6개). 커먼 자원비용 -1 | 업그레이드 몰빵 정예 |
| 📐 전략가 | 필드 시작 +1 (7장). 인접 조건 2칸으로 확장 | 넓은 필드, 긴 체인 |
| 📚 수집가 | 서로 다른 카드 종류 1개당 전체 ATK +1 | 다양한 카드, 합성 안 함 |
| ⚔️ 약탈자 | 전투 승리 시 골드 +2. 3연승마다 커먼 업그레이드 | 연승 유지, 전투 중심 |
| 💰 연금술사 | 판매 손실 없음. 매 라운드 골드 +1 | 자유 실험, 빌드 전환 |

설계 검증: 수집가(합성 안 함) vs 도박꾼(★3 올인) = **완전히 반대 전략**. 같은 게임이 다르게 느껴짐.

## 2. 장신구/부적

커맨더와 조합하여 세부 전술을 조절. 커맨더가 "방향", 부적이 "세기".
상세: [talismans.md](talismans.md)

**성장 부적:**
- 🔥 부싯돌: 매 라운드 첫 성장 이벤트 효과량 2배
- 💧 수은 방울: 강화 효과 발동 시 효과량 +25%
- 🥚 깨진 알: ★2 이상 카드의 유닛 추가 시 +1기

**전투 부적:**
- 💀 금간 해골: 유닛 첫 치사 피격 HP 1 생존 (유닛당 1회)
- 🥁 전쟁 북: 아군 유닛 수 > 적이면 적 전체 ATK -10%

**경제 부적:**
- 👁️ 유리 눈: 리롤 시 보유 카드 등장 확률 ×1.15
- 🪙 양면 동전: 매 라운드 상점 카드 1장 50% 할인 + 1장 50% 할증
- 🔧 녹슨 렌치: 업그레이드 분리 가능, 테라진 50% 환급

**빌드 부적:**
- 👜 터진 자루: 업그레이드 상점 표시 +1 (2→3)
- 🔌 구리 전선: 풀슬롯 카드의 업그레이드 효과가 인접 카드에 30% 전파

**변칙 부적:**
- 🎲 황금 주사위: 보스 보상 선택지 +2 (4→6)
- 🏺 영혼 항아리: 라운드 첫 판매 시 유닛 절반을 필드 카드에 배분

## 커맨더 × 부적 핵심 시너지

```
도박꾼  × 유리 눈    = ★3 올인 + 카드 찾기 가속. 가장 직관적 조합.
도박꾼  × 황금 주사위 = 보스 6택1. ★승급 + 영구규칙 최적 선택.
양성가  × 금간 해골  = 대군 전원 1회 생존. 물량의 압도적 생존력.
양성가  × 전쟁 북    = 항상 수적 우위 → 적 ATK -10%. 물량의 전투 보상.
단조사  × 구리 전선  = 6슬롯 풀채우기 → 업그레이드 인접 전파. 정예 허브.
전략가  × 황금 주사위 = 📐구조 확률 67%. 필드 9장 가능성 대폭 증가.
수집가  × 양면 동전  = 할인 카드 다양하게 활용. "싸니까 사볼까?" 탐색.
수집가  × 영혼 항아리 = 판매로 유닛 재분배. 합성 대신 판매 성장.
약탈자  × 전쟁 북    = 연승으로 병력 유지 + 수적 우위 디버프. 눈덩이.
연금술사 × 녹슨 렌치 = 에픽 구매 + 기존 업글 분리 교체. 최적 빌드.
```

안티 시너지(-)도 의도적: 수집가 + 깨진 알 = 합성 안 하는데 ★2 조건. 어렵지만 "1장만 ★2" 고급 플레이 가능.

## 3. 난이도 (누적식)

각 단계가 이전 모든 효과에 누적.

```
난이도 1 ⬜ 신병:   기본
난이도 2 🟩 병장:   적 HP ×1.2
난이도 3 🟦 하사:   시작 골드 약 -23% (13→10 스케일 보존, 최소 1/최대 3 페널티)
난이도 4 🟪 중사:   적 유닛 수 ×1.10 (초기안 ×1.3/×1.15에서 sim cliff 완화)
난이도 5 🟧 소위:   보스 라운드(R4/R8/R12/R15)가 커먼 업그레이드 보유
난이도 6 🟥 대위:   기본 상점 4장 (현재 6→4). 리롤 2골드
난이도 7 ⬛ 장군:   적 ATK ×1.10. 중후반 보스가 레어/에픽 업그레이드 보유
난이도 8 💀 전설:   플레이어 HP 20 (30→20)
```

난이도 5+에서 **적이 업그레이드를 보유** = 질적으로 다른 경험. 단순 숫자 인플레이션이 아님.

현재 구현 매핑:
- 난이도는 `Difficulty` autoload의 누적 보정 레이어로 적용한다. 기본 라운드 곡선, 카드 데이터, genome 값은 직접 수정하지 않는다.
- 난이도 3은 옛 13→10의 상대 페널티를 현재 economy scale에 맞춰 적용한다. 예: 13골드 시작은 10골드, 현재 best genome의 3골드 시작은 2골드.
- 난이도 4는 적 생성 후 현재 유닛 수의 10%를 추가 복제한다. 작은 초반 편성은 floor 처리로 부당한 반올림 cliff를 피한다. 초기안 ×1.3과 1차 ×1.15는 D4 clear cliff를 만들어 보류했다.
- 난이도 5 보스는 무작위 커먼 업그레이드 1개를 적 부대 전체에 적용한다.
- 난이도 7 보스는 R12에서 레어 1개, R15에서 에픽 1개를 추가한다. R4/R8은 커먼만 보유하고, R15는 레어와 에픽을 중첩하지 않는다.
- 난이도 6의 기본 상점 4장은 보스 보상 상점 확장보다 먼저 적용한다. 즉 상점 확장 보상은 4장 위에 추가된다.

## 해금 (메타 진행 루프)

```
초기 해금: 커맨더 2종 (도박꾼, 양성가) + 부적 3종 + 난이도 1

업적으로 해금:
  "유닛 120+ 필드"         → 전략가 해금
  "업그레이드 16+ 장착"     → 단조사 해금
  "서로 다른 카드 7종 필드"  → 수집가 해금
  "8연승"                  → 약탈자 해금
  "한 런에 카드 20장+ 판매" → 연금술사 해금

부적 업적 해금:
  "성장 효과 120회"         → 수은 방울 해금
  "★2+ 카드 5장 보유"       → 깨진 알 해금
  "수적 우위 전투 5승"       → 전쟁 북 해금
  "업그레이드 12+ 장착"     → 녹슨 렌치 + 터진 자루 해금
  "한 런에 카드 12장+ 판매" → 영혼 항아리 해금

클리어 보상:
  난이도 N 클리어 → 난이도 N+1 해금 + 전용 부적 해금

  리플레이 볼륨:
  커맨더 7 × 부적 12 × 난이도 8 = 672 시작 조합
  실질 의미 있는 조합 ~200가지 × 25분 = 수백 시간
```

현재 구현 노트:
- 양성가는 초기 해금 커맨더이므로, "유닛 50+ 필드" 업적은 현재 잠긴 커맨더인 전략가 해금으로 적용한다.
- 런 종료 시점에 런 중 최고 필드 유닛 수, 최고 장착 업그레이드 수, 최고 필드 유니크 카드 수, 최고 연승, 판매 수, 성장 체인 횟수, ★2+ 카드 수, 수적 우위 승리 횟수를 평가한다.
- 첫 런 튜토리얼은 런 시작 화면의 짧은 가이드로 제공하고, `START RUN` 이후 `tutorial_seen`으로 저장해 다음 런부터 접는다.
- 런 시작 화면의 `PROGRESS` 패널에서 전체 커맨더/부적 해금 상태, 완료 업적, 잠긴 목표를 확인할 수 있다.
- 첫 런 BuildPhase에는 dismiss 가능한 `TUTORIAL` 힌트 패널을 표시한다. 카드 구매, 벤치→필드 배치, 업그레이드 구매, 업그레이드 대상 선택, BUILD 확정 준비 상태에 맞춰 문구가 바뀐다.
- 런 종료/다음 시작 화면의 최근 해금 표시는 한 번에 3개를 우선 노출하고 나머지는 `PROGRESS`에서 확인하도록 요약한다. 이는 표시 페이싱만 조절하며, 획득한 커맨더/부적/난이도는 즉시 사용 가능하다.
