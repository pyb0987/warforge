# 보스 보상 (27개)

> R4/R8/R12 보스 격파 시 전용 풀에서 4개 표시, 1개 선택. 스킵 불가.
> R4: ⚡2 / 🔄4 / 💥2 / 📐1 (12g 기준선)
> R8: ⚡2 / 🔄6 / 💥1 / 📐0 (r8_6 +23% 전체 ATK 기준선)
> R12: ⚡2 / 🔄5 / 💥1 / 📐1 (r12_2 +25%/+25% 기준선)
> 유형별 설계 원칙은 game-loop.md 참조.

## R4 보스 — "기반"

빌드 방향을 설정하는 수준의 보상.

```
[R4-1] ⚡ 긴급 보급
즉시: 카드 1장 선택 → 해당 카드 ★승급 1회 + 4 테라진 획득.
  초반 핵심 카드를 ★2로 올려 R5~R7 안정화.

[R4-2] ⚡ 긴급 자금
즉시: +12 골드 획득.
  R4 보상 기준점. 다른 R4 보상은 "12g 즉시 수령"보다 지나치게 강하지 않게 설계.

[R4-3] 🔄 연쇄 반응로
영구: 유닛 추가(제조/부화/징집 등) 시 25% 확률로 추가 1기 생성.
  물량 빌드의 핵심 규칙. 모든 유닛 추가 효과에 적용.

[R4-4] 🔄 상점 확장
즉시: 무료 리롤 5회. 영구: 매 라운드 시작 시 무료 리롤 +1회.
  리롤 폭격 + 영구 매턴 +1로 빌드 수렴 가속.

[R4-5] 🔄 강화 증폭기
영구: 모든 ATK% 강화 효과 +20% 증폭 (예: 3% → 3.6%).
  성장 체인의 효율을 1.2배. 강화 의존 빌드에서 누적.

[R4-6] 🔄 자동 징집
영구: 매 라운드 시작 시 필드 위 모든 카드에 유닛 1기 추가.
  빌드 무관 물량 증가. R5부터 매 라운드 +카드 수만큼 유닛.

[R4-7] 💥 정예 각성
즉시: 카드 1장 선택 → 해당 카드 전체 유닛 ATK +30%, HP +30% 영구 강화.
  핵심 카드 즉시 강화. 대상 선택이 의미 있는 결정.

[R4-8] 💥 보급 호송
즉시: 랜덤 T4 카드 1장 + T3 카드 1장 획득 (T4 우선, 벤치 만석 시 못 받음).
  R4 시점 일반 상점에 거의 안 나오는 고티어 카드를 직접 확보. 강한 T4가 나오면 빌드 가속.

[R4-9] 📐 확장 벤치
영구: 벤치 +2칸.
  카드 보관 여유 → 합성 재료 확보 용이.
```

## R8 보스 — "전환"

R4보다 확실히 강력한 파워 스파이크.

```
[R8-1] ⚡ 대규모 징집
즉시: 카드 1장 선택 → 해당 카드 ★승급 1회 + 무료 레어 업그레이드 부착.
  ★승급 + 레어 동시 획득. 단일 카드 강화.

[R8-2] ⚡ 전쟁 기금
즉시: 18 골드 + 4 테라진 획득.
  경제 주입 (즉시 + 유연성). r8_4(영구 이자)와 차별: 이중 자원 + 즉시성.

[R8-3] 🔄 장인의 회수
영구: ★ 합성 시 합성 대상 티어 비용만큼 골드 환급 (★1→★2, ★2→★3 모두 적용).
  사실상 카드 1장 무료. T4 ★2 = 5×3 → 5×2=10g. 합성 빌드 가속.

[R8-4] 🔄 무한 금고
영구: 이자 cap 무제한 (5g당 +1g 이자, cap 제거).
  골드 모으기 빌드 보강. 평균 빌드(20~30g 보유)에는 영향 적음.

[R8-5] 🔄 광역 강화장
영구: ATK% 강화 효과 발동 시 양쪽 인접 카드에도 50% 강화 적용 (예: 본체 +10% → 인접 +5%).
  단일 강화가 범위 강화로. 배치 순서가 더 중요해짐.

[R8-6] 🔄 승전 의지 (R8 기준선)
영구: 전투 승리 시 필드 위 모든 카드 ATK +3% 영구 강화.
  승리할수록 강해지는 눈덩이. 7라운드 전승 시 +23% 전체 ATK.

[R8-7] 💥 유전자 강화
즉시: 카드 1장 선택 → 무료 에픽 업그레이드 1개 부착.
  단일 카드 강화. 에픽 업그레이드의 강도가 가치를 결정.

[R8-8] 🔄 방어선 구축
영구: 필드 위 모든 카드의 유닛 DEF +2.
  flat 데미지 차감. 약한 적(ATK 10~20)에게 큰 효과, 강한 적에도 유의미.

[R8-9] 🔄 전선 확장
영구: R13 전투 승리 시 R12 보상 풀에서 1개 추가 선택 (1회 한정).
  R13 도달 = R12 보스 격파 성공. 사실상 R12 보상 ×2.
```

## R12 보스 — "완성"

단독으로 게임을 바꾸는 수준.

```
[R12-1] ⚡ 궁극 진화
즉시: ★2 카드 1장 → ★3, 그 다음 ★1 카드 1장 → ★2 (순서 강제).
  한 보상에 ★1을 ★3으로 올릴 수 없음 (★1 → ★3 직행 방지). 잘못된 ★ 카드 전달 시 효과 무시.

[R12-2] ⚡ 제국의 유산 (R12 기준선)
즉시: 필드 위 모든 카드 ATK +25%, HP +25% 영구 강화.
  전체 즉시 강화. R13~R15 대비. 테라진 보너스 제거 (단순화).

[R12-3] 🔄 과부하 연쇄
영구: 필드 위 모든 카드의 발동 상한(max_activations) +1.
  체인 빌드 강 빌드 +25% 부근 (r12_2 기준선). 너프 (이전 +2 → +1).

[R12-4] 🔄 상점 대확장
영구: 상점 슬롯 +2 (6→8) + 매 라운드 시작 시 무료 리롤 +2.
  R12 사이즈 효과의 한 축. r4_4(매턴+1리롤)와 동시 보유 시 매 라운드 무료 리롤 합산 = +3회.

[R12-5] 🔄 오색 군단
영구: 매 라운드 시작 시 보드 distinct 테마 개수당 ATK +10%, HP +10% (전투 한정 buff).
  중립 포함 5테마 × 10% = +50%/+50%. 멀티 테마 빌드 직격. 매 라운드 갱신.

[R12-6] 🔄 물량의 법칙
영구: 유닛 50기 이상인 카드의 ATK ×1.4, AS ×1.2(공격속도 20% 증가).
  물량 빌드 전용 보너스. 50기 조건이 빌드 방향을 확정. 너프 (이전 ×1.5/×1.3).

[R12-7] 💥 신의 일격
즉시: 카드 1장 선택 → 무료 에픽 + 레어 업그레이드 1개씩 부착 (총 2개).
  단일 카드 업글 집중 패키지. ATK×2 폐기. 슬롯 부족 시 부착 안 됨.

[R12-8] 🔄 전사의 영혼
영구: 매 전투 시작 시 보드 부활 풀 20기 활성. 처음 사망한 아군 20기 100% HP 부활 (전투당 풀 리셋).
  군대/드루이드 정예 빌드 직격. 군대 통합사령부 revive(개체)와 별도 풀로 stack (revive_left 우선, 그 다음 boardpool).

[R12-9] 📐 차원 균열
영구: 필드 +1칸 + 필드 위 모든 카드의 업그레이드 슬롯 +1.
  구조 확장 복합 보상. 카드 1장 + 슬롯 1개.
```
